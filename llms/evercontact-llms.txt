# Evercontact

> AI-powered contact intelligence that automatically extracts, enriches, and syncs
> contact data from email signatures across Google Workspace and Microsoft 365. A
> multilingual model parses names, titles, phones, and addresses from the signature
> block of every email (30+ languages), deduplicates and enriches person records,
> and syndicates clean contacts to CRMs and address books. A REST API and webhook
> event stream are available for custom integrations. This file was generated by the
> API Evangelist enrichment pipeline from the public site and catalog artifacts.

## API
- [Evercontact API](https://www.evercontact.com/api.html): REST API — parse, enrich, contacts, webhooks, events. Base URL https://api.evercontact.com, versioned /v1, Bearer-token auth.

## Operations
- POST /v1/parse: Extract a structured contact from email signature text.
- POST /v1/enrich: Complete a known contact with verified details.
- GET /v1/contacts/{id}: Retrieve the canonical deduplicated person record.
- POST /v1/webhooks: Register a webhook subscription endpoint.
- GET /v1/events: Paginated stream of relationship-change events (contact.created, contact.updated, company.linked).
